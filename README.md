# 健康記録アプリ(自分専用PWA)

写真・音声・テキストで食事や体重を送ると、AI(Gemini)が内容を判定して
Googleスプレッドシートに自動で書き込むアプリです。

## 仕組み

```
iPhoneのアプリ(GitHub Pages) → GASウェブアプリ → Gemini API(判定)
                                      ↓
                              Googleスプレッドシート
```

- **docs/** … スマホで開く画面。GitHub Pagesに公開し、Safariの「ホーム画面に追加」で使う
- **gas/** … Google Apps Script(裏側)。あなたのGoogleアカウント内で動き、シートの読み書きとGemini呼び出しを行う
- GeminiのAPIキーと合言葉(TOKEN)はGASの中にだけ置く。スマホ側には保存しない

## セットアップ手順

### 1. Gemini APIキーを取得(無料)

1. [Google AI Studio](https://aistudio.google.com/apikey) を開き、Googleアカウントでログイン
2. 「APIキーを作成」を押し、表示された文字列をコピーしておく

### 2. GAS(裏側)を設置

1. 対象のスプレッドシートを開く → メニュー「拡張機能」→「Apps Script」
2. `gas/` フォルダ内の4ファイル(`main.gs` `sheets.gs` `gemini.gs` `setup.gs`)の中身を、
   Apps Scriptエディタに同名で貼り付ける(`appsscript.json` は「プロジェクトの設定」で
   「appsscript.jsonをエディタで表示」をオンにして貼り付ける)
3. 左メニュー「プロジェクトの設定」→「スクリプトプロパティ」で以下を追加
   - `SPREADSHEET_ID` … シートURLの `/d/` と `/edit` の間の文字列
   - `GEMINI_API_KEY` … 手順1でコピーしたキー
4. エディタで `setup` 関数を選んで実行(初回は権限の承認画面が出るので許可)
   - ログに **合言葉(TOKEN)** が表示されるのでコピーしておく
   - シートに「定番マスタ」「設定」タブが自動で追加される
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - デプロイ後に表示される **ウェブアプリのURL**(`…/exec`)をコピーしておく

※「アクセスできるユーザー: 全員」にしても、合言葉が一致しないリクエストは
すべて拒否されるため、他人はシートを読み書きできません。

### 3. 画面(PWA)をGitHub Pagesに公開

リポジトリの Settings → Pages で「Deploy from a branch」を選び、
ブランチ `main` の `/docs` を指定して公開する。

### 4. iPhoneに設置

1. SafariでGitHub PagesのURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. アプリを開き、⚙(設定)から以下を入力して保存
   - GASウェブアプリのURL(手順2-5)
   - 合言葉(手順2-4)
   - 目標カロリー・目標たんぱく質

## 使い方

- **写真**: 栄養成分表示・体重計の画面・ヘルスケアの歩数・手書き筋トレメモを撮って送る
- **音声**: 「朝食プロテイン」「体重57.2キロ」「8月15日 歩数8200歩」のように話す
- **テキスト**: 同じ内容を文字で送る
- 定番メニュー(★)に登録した食事は、名前が一致すると確認なしで即記録
- 間違えたら、ホームの「取り消す」で直近1件を元に戻せる

## 書き込み先のルール

- 「YYYY」タブ … 体重(B)・摂取カロリー(D)・歩数(F)。平均などの数式列(C/E/G/H)には触らない
- 「YYYY日常記録」タブ … 体重(B)・体脂肪率(C)・朝食〜間食(D〜G)・筋トレ(H)・総摂取カロリー(I)・総たんぱく質(J)
- 食事と筋トレは追記、体重・体脂肪率・歩数は上書き(既に値がある場合は確認してから)
- 1月1日をまたぐと、前年のタブをコピーして新しい年のタブを自動作成

## 注意

- 年が変わった直後の数日は、2週間平均などの数式が前年データを参照できないため
  空欄やエラーになることがあります(データが溜まると自然に直ります)
- まずはシートをコピーしたテスト用シートのIDで動作確認してから、
  本番シートのIDに切り替えるのがおすすめです
